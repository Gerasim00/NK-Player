# NK Player

Неофициальный музыкальный плеер ВКонтакте для Windows (Electron). Работает через ту же сессию, что и веб-версия vk.ru/`: внутренний API `al_audio.php`, расшифровка ссылок и прямые `okcdn`-стримы.

> 🚀 **Свежесть в 1.4.6**
> - Ускоренная загрузка треков: приоритет прямых mp3-источников, параллельный прогрев HLS, `startFragPrefetch`
> - Постоянный кэш треков на диске — раз скачанный трек открывается мгновенно, без сети
> - Фоновое скачивание текущего + следующих треков
> - Виртуализированный список — плейлисты на 500+ треков не тормозят при ресайзе
> - Панель настроек: кроссфейд, нормализация громкости, бас, surround, затухание при паузе, лимит/очистка кэша

## Возможности

- Моя музыка, плейлисты, поиск и треки артистов
- Эквалайзер (10 полос + пресеты)
- Очередь, shuffle, repeat
- Discord Rich Presence (статус с играющим треком)
- Локальная музыка и свои плейлисты (в профиле приложения)

## Как это работает приватность-wise

- Приложение **не передаёт логин и пароль** куда-либо — вход происходит на странице vk.ru (или через QR).
- Ссылки на треки получает с той же сессии cookies; запросы к CDN выполняются с заголовками веб-плеера.
- Кэш треков лежит локально в `%APPDATA%/NK Player/song-cache` и управляется лимитом в настройках.

## Сборка из исходников

```powershell
npm install          # node_modules
npm.cmd start        # запуск из исходников
npm.cmd run installer   # установщик: dist\NK-Player-Setup-<версия>.exe
npm.cmd run pack        # портативная папка (electron-packager)
```

> В PowerShell с включённой ExecutionPolicy команды `npm` вызываются как **`npm.cmd`**.

### Версии и релизы

- Текущая версия — в `package.json` (`npm.cmd version X.Y.Z --no-git-tag-version`).
- Проверка обновлений сравнивает **текущую версию приложения** с тегом последнего релиза на GitHub, поэтому тег релиза следует делать вида `v1.4.6`.
- Артефакт для релиза: `dist\NK-Player-Setup-1.4.6.exe` (+ `.blockmap` для будущих диффов).

## Юридическое

NK Player — неофициальный клиент. Приложение не связано с ООО «ВКонтакте» и не является его продуктом. Для прослушивания музыки используется действующая подписка пользователя, без обхода каких-либо ограничений.
