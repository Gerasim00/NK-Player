# NK Player

Музыкальный плеер для ВКонтакте на базе Electron.

![NK Player](assets/icon.png)

Наш Discord сервер - https://discord.gg/BhhtUum3R2

## Возможности

### 🎵 Музыка ВКонтакте
- **Вход через QR-код** во встроенном окне vk.ru: сканируете код приложением ВК на телефоне, логин и пароль вводить не нужно
- **Моя музыка, плейлисты, поиск и треки артистов** — один и тот же список с количеством треков и общей длительностью в подзаголовке
- **Постоянный кэш треков** — прослушанные композиции сохраняются локально и не загружаются повторно
- **Ускоренная загрузка** — приоритет прямых mp3-источников, параллельный прогрев HLS, фоновое скачивание текущего и следующих треков
- **Виртуализация списка** — при длинных списках в DOM живёт только видимое окно строк

### 🎧 Воспроизведение
- **10-полосный эквалайзер** (31 Гц – 16 кГц) с 7 пресетами и предусилителем
- **Эффекты звука**: последовательный кроссфейд 0–12 с, нормализация громкости, усиление баса, surround-виртуализация, затухание при паузе
- **Очередь воспроизведения** — отдельный раздел, добавление треков «следующим» и в конец очереди
- **Shuffle и повтор** (`off → all → one`), состояние запоминается между запусками
- **Восстановление сессии** — очередь, трек и позиция возвращаются при запуске, звук сам не включается
- **Горячие клавиши**: `Space`, `←` / `→`, `Ctrl+←` / `Ctrl+→`, `Ctrl+F`, `Ctrl+E`, `Esc`
- **Media Session** — метаданные трека и системные кнопки play/pause/next/prev

### 📁 Локальная музыка
- Импорт **MP3 / FLAC / WAV / OGG** (а также m4a, aac, opus, wma, mp4); у MP3 читаются ID3-теги и обложка
- Создание, переименование и удаление **своих плейлистов**, добавление в них треков

### 🌌 Главная сцена
- Голограмма кота и подиум со спектрографом, реагирующим на музыку
- Настройка спектрографа: толщина и длина лучей, количество (24–96), плотность точек, интенсивность баса, середины и верхов, общий выключатель

### ⚙️ Интеграция и настройки
- **Статус в Discord**: что играет с прогрессом; отключается кнопкой **DC**
- **Панель настроек** из четырёх групп: «Воспроизведение», «Спектрограф», «Служебное», «О программе»
- **Проверка обновлений** — при запуске и по кнопке «Проверить» в сайдбаре

## Статус в Discord

При воспроизведении NK Player показывает в профиле Discord строку «Слушает NK Player»
с исполнителем, названием трека и полосой прогресса.

- Работает только с десктопным клиентом Discord на той же машине
- Если Discord не запущен, приложение продолжает работать и подключается само, когда клиент появится
- Отключается кнопкой `DC` в правом нижнем углу; выбор запоминается

Чтобы собрать со своим Discord-приложением, замените `CLIENT_ID` в `discord-rpc.js`
на Application ID из [Developer Portal](https://discord.com/developers/applications).
Картинки статуса берутся из Rich Presence → Art Assets с ключами `nk_logo`, `nk_play`, `nk_pause`.

## Что не синхронизируется с ВК

Плеер только читает данные ВК: треки, плейлисты и поиск подтягиваются оттуда,
но изменения из плеера в ВК не отправляются и хранятся на этом компьютере.

- **Свои плейлисты** — создание, переименование, удаление, добавление и удаление треков.
  Лежат в `%APPDATA%\NK Player\playlists.json` и в ВК не появятся.
- **Загруженная музыка** — файлы копируются в профиль плеера и в ВК не загружаются.
- **Очередь, эквалайзер и настройки** — сохраняются только в плеере.

Плейлисты ВКонтакте по-прежнему доступны только для чтения.

## Установка (готовый установщик)

Скачайте `NK-Player-Setup-1.5.0.exe` со страницы [Releases](../../releases) и запустите.

- Установка для текущего пользователя, без прав администратора
- Создаёт ярлыки на рабочем столе и в меню «Пуск»
- Данные профиля хранятся в `%APPDATA%\NK Player`

## Сборка из исходников

**Требования:** Node.js 18+, npm

```bash
# Установить зависимости
npm install

# Запустить в режиме разработки
npm start

# Собрать установщик (Windows x64)
npm run build
```

Готовый установщик появится в `dist/NK-Player-Setup-1.5.0.exe`.

## Структура проекта

```
├── main.js          # Главный процесс Electron (окно, IPC, миграция профиля)
├── renderer.js      # Рендер-процесс (UI, очередь, эквалайзер, плейлисты)
├── vk-audio.js      # Работа с API ВКонтакте (треки, профиль, HLS)
├── song-cache.js    # Постоянный кэш треков на диске
├── local-music.js   # Импорт и хранение локальных файлов
├── library.js       # Локальные плейлисты (playlists.json)
├── updates.js       # Проверка обновлений по GitHub Releases
├── discord-rpc.js   # Статус «Слушает» в Discord
├── index.html       # Разметка и стили
└── assets/
    ├── icon.ico     # Иконка приложения
    ├── icon.png     # Иконка для UI
    └── holo-cat.png # Голограмма кота на главной
```

## Технологии

- [Electron](https://www.electronjs.org/) 44
- [hls.js](https://github.com/video-dev/hls.js/) — воспроизведение HLS-потоков ВКонтакте
- [@xhayper/discord-rpc](https://github.com/xhayper/discord-rpc) — Rich Presence
- Web Audio API — эквалайзер
- Node.js `fs` — хранение локальной музыки и плейлистов
